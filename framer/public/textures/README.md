# Texture Assets

This directory is reserved for texture maps (albedo, normal, roughness, etc.) used by Framer 3D components.

## Suggested Sources

All suggested sources offer assets that are free for commercial use and redistribution:

- [Poly Haven](https://polyhaven.com/textures) — CC0 texture library
- [AmbientCG](https://ambientcg.com/list?type=Texture) — CC0, physically based textures
- [CGBookcase](https://cgbookcase.com/textures/) — CC0 materials

When adding textures:
- Prefer PNG, JPEG, or WebP formats for compatibility
- Name files using `kebab-case` (e.g., `metal-plate-albedo.png`)
- Include any required attribution in `ATTRIBUTION.md`
