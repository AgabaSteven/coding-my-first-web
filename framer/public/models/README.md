# 3D Model Assets

This directory contains 3D models used by Framer components.

## Placeholder Model

A placeholder GLB model should be placed here as `placeholder.glb`.

### Recommended Sources (all MIT/CC0 licensed):

1. **Poly Pizza** (https://poly.pizza) - CC0 license, free 3D models
2. **Quaternius** (https://quaternius.com) - CC0 license, low-poly models
3. **Kenney** (https://kenney.nl/assets) - CC0 license, game assets
4. **Sketchfab** (https://sketchfab.com) - Filter by "Downloadable" and "CC0" or "CC-BY"

### Example models to use:

- Simple geometric shapes (cube, sphere, torus)
- Low-poly objects (tree, rock, building)
- Abstract sculptures

### Creating a simple placeholder:

You can create a simple box in Blender:
1. Open Blender
2. Delete default cube
3. Add -> Mesh -> Cube (or any shape)
4. File -> Export -> glTF 2.0 (.glb)
5. Save as `placeholder.glb` in this directory
